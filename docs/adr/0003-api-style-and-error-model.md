# ADR 0003: Стиль REST API та єдина модель помилок

* **Статус:** Прийнято
* **Дата:** 2026-11-17
* **Рішення:** Усі публічні ендпоінти W Store будуються у стилі REST JSON API та суворо відповідають специфікації `docs/api/openapi.yaml`.
* **Політика HTTP-статусів:**
  * `200 OK` — успішне отримання списку, одного запису або оновлення товару.
  * `201 Created` — успішне створення нового товару.
  * `204 No Content` — успішне видалення товару.
  * `400 Bad Request` — некоректні вхідні дані (помилка валідації)[cite: 6].
  * `404 Not Found` — товар із вказаним ID не знайдено[cite: 6].
  * `500 Internal Server Error` — внутрішня помилка сервера або БД.
* **Єдиний формат помилки (ErrorResponse):**
  Усі помилки клієнту повертаються у єдиному JSON-форматі[cite: 6, 7]:
  ```json
  {
    "error": "ValidationError",
    "code": "INVALID_INPUT",
    "details": [{ "field": "name", "message": "Назва товару є обов'язковою" }]
  }
