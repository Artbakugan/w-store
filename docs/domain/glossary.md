# Ubiquitous Language (Глосарій термінів W Store)

| Термін | Контекст | Визначення |
| :--- | :--- | :--- |
| **Product (Товар)** | Catalog | Одиниця товару в асортименті магазину з актуальною ціною та кількістю на складі. |
| **OrderItem (Позиція замовлення)** | Orders | Конкретний товар усередині замовлення клієнта. Зберігає зафіксовану ціну (`unitPrice`) на момент оформлення. |
| **Order (Замовлення)** | Orders | Запит покупця на придбання одного або кількох `OrderItem` із фіксованою сумою та статусом виконання. |
| **Stock (Залишок)** | Catalog | Кількість одиниць товару на складі, доступних для продажу. |
| **Customer (Покупець)** | Identity / Orders | Користувач із роллю `CUSTOMER`, який оформлює замовлення в магазині. |
| **Payment (Платіж)** | Payments | Операція оплати конкретного замовлення, після успіху якої замовлення переходить у статус `PAID`. |
| **Checkout (Оформлення)** | Orders | Процес перевірки наявності товарів, створення `Order` та ініціалізації `Payment`. |

## Уточнення термінів у різних контекстах
* **Товар (`Product` vs `OrderItem`):** У контексті **Catalog** сутність `Product` постійно оновлюється (може змінитись ціна чи назва). У контексті **Orders** використовується `OrderItem` — якщо ціна товару в каталозі зміниться після покупки, вартість уже створеного замовлення залишиться незмінною.
* **Користувач (`User` vs `Customer`):** У контексті **Identity** це обліковий запис (`User`) з email та роллю, а в контексті **Orders** він фігурує лише як ідентифікатор покупця (`customerId`).
