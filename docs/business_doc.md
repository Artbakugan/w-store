# Опис проєкту W Store

## Про проєкт
W Store — веб-застосунок для продажу спортивних товарів. Дозволяє переглядати каталог, шукати товари за категоріями та оформлювати замовлення.
Бекенд: Node.js, Express. База даних: SQLite.

## Ролі користувачів
- Гість: переглядає каталог.
- Покупець: додає товари в кошик, робить замовлення.
- Адмін: додає та редагує товари.

## Сценарії
1. Перегляд каталогу товарів.
2. Пошук та фільтрація.
3. Оформлення замовлення.

## Вимоги та обмеження
- Час відповіді API до 500мс.
- Простий адаптивний інтерфейс.
- Оплата при отриманні (без еквайрингу).
